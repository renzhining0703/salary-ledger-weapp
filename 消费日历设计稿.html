消费日历 · 独立页面设计稿

从「我的 → 消费日历」半屏 sheet 重构为独立页面 · 兼容深浅色 · 保留并升级现有热力图功能 · v1.0

月历视图 · 新增 热力视图 · 保留升级 深色模式 · 自动适配

1设计目标

  • 从弹层到页面：消费日历是高频回看的全局数据洞察，从 sheet 升级为独立页面，给足信息层级与操作空间。
  • 日历为主：进入即见完整月历，日期 + 当日消费热力色一目了然；原有 GitHub 热力图降为第二视图保留。
  • 零成本深浅色：全部沿用项目现有 CSS 变量（--bg/--card/--heat-0~4/--gold…），无任何硬编码色值。
  • 能力不减：近 3 月/半年/一年范围、统计条、单日流水明细、点击格子看当天，全部继承。

2页面信息架构

A自定义导航栏返回 + 「消费日历」+ 右侧「今天」快捷回跳
B月度概览卡本月支出大数字 · 日均 / 笔数 / 环比（深蓝渐变 hero）
C视图切换月历 ｜ 热力（segmented，默认月历）
D月历视图月份切换器 → 周标签 → 7 列网格 → 色阶图例
E热力视图近 3 月 / 半年 / 一年 · 横向滚动热力图 · 统计条
F当日明细点击日期/格子弹出：分类 + 备注 + 金额 + 「记一笔」

6交互清单

  • 点日期 → 弹出当日明细 sheet，格子进入「选中」态；无消费弹轻提示。
  • 月份切换器 ‹ › 前后翻月；导航栏「今天」一键回当前月并高亮今天。
  • 热力视图内点格子 → 同样弹当日明细（原功能不变）。
  • 明细底部「记一笔」→ 跳记账页并预填该日期（新增快捷能力）。
  • 深色模式随系统 / 手动主题自动生效，无需单独开关。
