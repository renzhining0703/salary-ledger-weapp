# 薪账本

微信小程序原生 + 微信云开发（数据云数据库 + 云函数定时提醒）个人记账工作台。

- **AppID**：`wx7326e353b2996845`
- **云开发环境 ID**：`cloud1-8gembxhfa18dcf14`

## 功能（4 个 Tab）

| Tab | 功能 |
|---|---|
| 首页 | 「今天要处理」置顶：还款日前1天黄标/当天红标/逾期红标 + 一键标记已还；**预算超支预警**（超支红条/达80%黄条）；**月度结余看板**（‹ 切换月份 › 收入/支出/还款/结余，正绿负红）；用户设置（头像/昵称/发薪日/月预算） |
| 工资 | 发薪日一次设置（每月X号，可修改）；记录发薪只填金额，日期自动带出；历史列表；下次发薪倒计时；年度累计收入 |
| 信用卡 | 多卡管理（卡名/每月还款日/应还金额）；已还/待还状态切换（标记已还时记录实际还款日期，用于看板还款归月）；逾期/明天/今天/已还状态自动判断 |
| 记账 | 分类开销录入（餐饮/交通/购物/孩子/居住/其他）；月预算进度条+**超支金额提示**；分类占比条形图；本月流水与上月对比；**本月账单**（点月度总览打开：分类饼图 + 同比/环比 + 储蓄率 + AI「账本君」解读） |

### 交互体验

- **骨架屏**：工资 / 信用卡 / 记账三个 Tab 首次进入显示加载骨架（呼吸闪烁占位），数据到达后平滑替换，不再白屏僵硬；已加载过的页面切换 Tab 静默刷新不闪屏
- **弹层动画**：所有底部弹层（记一笔 / 添加信用卡 / 编辑金额 / 记录发薪 / 发薪日设置 / 个人设置）均有滑入滑出动画，遮罩同步淡入淡出


## 月度结余看板说明

- 首页中间卡片，左右箭头切换月份，显示该月 **收入 / 支出 / 还款 / 结余**（结余 = 收入 − 支出 − 还款，正数绿、负数红）
- **还款统计口径**：已还的信用卡按「实际还款日期」归到对应月份；当前月未还的（pending）计入当月应还
- 标记某张卡已还后，自动记录还款日期，历史月份看板即可看到该笔还款

## 快速开始

### 1. 导入项目

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开开发者工具 → 导入项目 → 选择本项目目录 → AppID 填 `wx7326e353b2996845`
3. 首次打开后顶部工具栏会提示「未找到云环境」，点击工具栏 **「云开发」→ 开通云开发 → 记录环境 ID**（必须是你已有的 `cloud1-8gembxhfa18dcf14`）

### 2. 创建云数据库集合

打开开发者工具 → **云开发控制台** → **数据库** → 新建 4 个集合：

- `users` — 用户配置（发薪日、预算、昵称头像）
- `salary` — 工资记录
- `cards` — 信用卡记录
- `expenses` — 日常开销记录

> 创建集合后，将每个集合的权限设置为 **「仅创建者可读写」**（默认即可，这样每个用户只能读写自己的数据）。

### 3. 上传云函数

在开发者工具左侧「云函数」目录：

1. 右键 `cloudfunctions/login` →「创建并部署：云端安装依赖」
2. 右键 `cloudfunctions/remind` →「创建并部署：云端安装依赖」

> remind 云函数已配置定时触发器（每天 09:00 执行），部署后自动生效。

### 4. 订阅消息提醒（可选，建议开通）

还款日前一天自动推送到微信，需要订阅消息模板：

1. 登录 [小程序后台](https://mp.weixin.qq.com) → 功能 → **订阅消息** → 选用模板
2. 选一个「还款提醒」类模板（关键词建议包含：还款名称/日期/金额）
3. 拿到 **模板 ID**，填入两处：
   - `utils/config.js` → `SUBSCRIBE_TEMPLATE_ID`
   - `cloudfunctions/remind/index.js` → `TEMPLATE_ID`
4. 重新右键部署 `remind` 云函数
5. 在小程序内点击首页「还款提醒」按钮，授权一次即可（每授权一次可收到一次推送）

### 5. 隐私合规（上线前必填）

- 小程序后台 → **设置** → **基本设置** → **用户隐私保护指引** → 声明「收集用户头像、昵称」
- 后台 → **设置** → **用户隐私保护指引** → 按要求填写内容（本小程序仅收集头像、昵称用于显示）

## 数据安全

- 每个用户数据完全隔离（`openid` + 云数据库「仅创建者可读写」权限）
- 示例数据覆盖近 3 个月（含还款记录与超支演示），仅在首次进入时自动写入当前用户

## 常见问题

**Q：打开页面空白/没数据？**
A：首次进入时后台自动写示例数据，请稍等 1-2 秒后重进页面（tab 切换即可刷新）。若仍空白，按下方「自检三步」排查。

**Q：点击添加信用卡/工资/开销，提示成功但列表没出现？**
A：这是云函数 `login` 未部署成功导致的。列表加载会等登录完成，登录失败则一直不显示（数据其实已写入）。按下方「自检三步」修复后，重新进入页面即可。

### 自检三步（部署后必查）

1. **云函数已部署？** 左侧资源管理器 → 右键 `cloudfunctions/login` →「上传并部署：云端安装依赖」；`cloudfunctions/remind` 同样操作。**只有目录文件不算部署**。
2. **集合权限？** 云开发控制台 → 数据库 → 分别点开 `users / salary / cards / expenses` 4 个集合 → 权限设置 → 选「**仅创建者可读写**」（不是「所有用户不可读写」，那是默认值，会导致读写全失败）。
3. **云环境 ID？** `app.js` 与 `utils/config.js` 中的环境 ID 必须为 `cloud1-8gembxhfa18dcf14`。

> 判断是否连通：开发者工具控制台（Console）若无报错，且顶部显示「云开发环境已连接」即为正常。

**Q：想修改发薪日/月预算？**
A：两个入口：① 工资页顶部「每月X号发薪 · 修改」；② 首页点击顶部头像/昵称区域 → 「个人设置」。

**Q：想清空示例数据用自己的？**
A：首页 → 顶部头像 → 设置弹层底部「重置全部数据」→ 二次确认。重置会清空当前账号所有记录（含用户配置），重新打开小程序会重新预置示例数据，之后把示例记录逐条删除（或直接在云开发控制台删集合数据）再录自己的真实数据。

**Q：云函数部署后 remind 没推送？**
A：检查 `remind/index.js` 中的 `TEMPLATE_ID` 是否已替换为真实模板 ID；检查数据库 `cards` 是否有还款日 = 明天的 pending 卡片。
